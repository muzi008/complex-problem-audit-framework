**相关性**表示两个变量经常一起变化；**因果性**表示其中一个变量的变化会直接导致另一个变量变化。两者不等同，因为相关关系可能来自：

- **共同原因**：第三个变量同时影响二者；
- **反向因果**：可能是结果影响原因；
- **巧合或样本偏差**：观察到的同步变化未必稳定存在。

**生活中的例子：**  
夏天冰淇淋销量增加时，溺水事故也往往增加。两者存在正相关，但不能因此说“吃冰淇淋导致溺水”。真正的共同原因是**天气炎热**：高温既让更多人买冰淇淋，也让更多人去游泳，从而增加溺水风险。

因此，要判断因果关系，通常还需要排除其他解释，并观察“主动改变一个因素后，结果是否随之改变”。
