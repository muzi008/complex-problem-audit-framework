**相关性**只说明两个变量经常一起变化；**因果性**则意味着其中一个变量的变化会直接导致另一个变量变化。

相关性不等于因果，主要因为：

1. **可能存在第三个因素**，同时影响两者；
2. **因果方向可能相反**，不一定是 A 导致 B；
3. **可能只是巧合**，尤其在样本较小或比较很多变量时。

**生活中的例子：**

夏天，冰淇淋销量上升，同时溺水事故也增多。两者存在正相关，但不能因此说“吃冰淇淋导致溺水”。

真正的共同原因是**天气炎热**：

- 天热使更多人购买冰淇淋；
- 天热也使更多人去游泳，从而增加溺水事故。

所以，要判断因果关系，除了观察相关性，还需要排除其他解释，并通过实验、自然实验或严谨的统计设计来验证。
