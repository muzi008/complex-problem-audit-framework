相关性表示两个变量经常一起变化；因果关系则表示一个变量的变化会直接导致另一个变量变化。

相关性不等于因果，常见原因有：

- **第三变量影响两者**：A 和 B 同时由 C 导致。
- **因果方向可能相反**：可能是 B 导致 A，而不是 A 导致 B。
- **巧合或数据偏差**：尤其在样本小、比较次数多或取样不当时。

**生活例子：**

夏天，冰淇淋销量增加，同时溺水事故也增加。两者存在正相关，但不能说“吃冰淇淋导致溺水”。真正的共同原因是**气温升高**：天气热使更多人购买冰淇淋，也使更多人去游泳，从而增加溺水事故。

要更接近因果结论，通常需要排除其他解释，并结合随机实验、自然实验、时间顺序或其他因果识别方法。
