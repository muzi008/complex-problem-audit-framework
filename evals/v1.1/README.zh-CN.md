# CPAF v1.1.0 定向测试数据

本目录保存 v3.1.1 Final / CPAF v1.1.0 的补丁准入证据。题面均为通用测试案例，不含用户聊天原文、账户信息或本机绝对路径。

## 测试问题

三条候选分别接受两道目标题和一道控制题：

| 候选 | 目标题 | 控制题 |
|---|---:|---:|
| 条件性观察者偏差审计 | O1、O2 | O0 |
| 命题跨层检查 | C1、C2 | C0 |
| 结果机制检查 | R1、R2 | R0 |

每道题先比较 `CORE-3.0.1` 与 `CORE-3.0.1 + 单条候选补丁`。首轮共 9 道题、18 份答案、9 组成对盲评。观察者候选随后对 O1、O2、O0 各追加两次重复，共 12 份答案、6 组成对盲评。

## 结果

| 候选 | 补丁胜 | 旧版胜 | 平 | 处理 |
|---|---:|---:|---:|---|
| 观察者偏差，合并两轮 | 3 | 0 | 3 | 条件进入 CORE |
| 命题跨层，首轮 | 0 | 0 | 3 | 只保留为 Eval 回归题 |
| 结果机制，首轮 | 0 | 0 | 3 | 只保留为 Eval 回归题 |

观察者三组控制比较全部为平局，没有出现多余心理分析。复测中一次硬失败来自旧版遗漏沉没成本，补丁版没有硬失败。

## 最终运行提示发布门

候选补丁测试完成后，又直接比较 Git 标签 `v1.0.1` 和待发布 `v1.1.0` 中的真实中文运行提示。9 道题先各运行一次，观察者 O1、O2、O0 再各追加两次，共 30 份回答、15 组成对盲评。

| 题组 | 题型 | 新版胜 | 旧版胜 | 平 | 硬失败 |
|---|---|---:|---:|---:|---:|
| 命题跨层 | 目标题 | 1 | 0 | 1 | 0 |
| 命题跨层 | 控制题 | 0 | 0 | 1 | 0 |
| 观察者偏差 | 目标题 | 3 | 1 | 2 | 0 |
| 观察者偏差 | 控制题 | 0 | 0 | 3 | 0 |
| 结果机制 | 目标题 | 0 | 0 | 2 | 0 |
| 结果机制 | 控制题 | 1 | 0 | 0 | 0 |

观察者 O2 三次分别为新版胜、旧版胜、平各一次。旧版胜出的比较中，两份答案都达到标准，未出现新版硬失败；旧版优势没有在同类重复中再次出现。该结果按原样公开，没有删除失败比较。

## 文件

- `initial-generations.json`：首轮 18 份回答及题面、标准和 Token 记录；
- `initial-judgments.json`：首轮 9 组匿名评审；
- `observer-repeat-generations.json`：观察者复测 12 份回答；
- `observer-repeat-judgments.json`：观察者复测 6 组匿名评审；
- `initial-summary.csv`、`observer-repeat-summary.csv`：汇总；
- `outputs/`、`observer-repeat-outputs/`：逐题 Markdown 回答；
- `scripts/`：本轮实际使用的 PowerShell 测试脚本。
- `release-gate/`：真实 `v1.0.1` 与 `v1.1.0` 运行提示的 30 份回答、15 组盲评和汇总表。

JSON 中删除了本机输出路径，保留题面、回答、盲评理由、Token 与条件信息。

逐题 Markdown 按生成原文保留，包括模型使用的行尾双空格；JSON 中的 `content` 可用于核对原文一致性。

## 复现

脚本需要一个兼容 OpenAI Chat Completions 的接口。默认地址是 `http://127.0.0.1:10100/v1/chat/completions`，可通过参数覆盖：

```powershell
pwsh ./evals/v1.1/scripts/run_patch_eval.ps1 `
  -Gateway 'http://127.0.0.1:10100/v1/chat/completions' `
  -Model 'gpt-5.6-sol' `
  -JudgeModel 'gpt-5.6-terra'

pwsh ./evals/v1.1/scripts/run_observer_repeat.ps1 `
  -Gateway 'http://127.0.0.1:10100/v1/chat/completions' `
  -Model 'gpt-5.6-sol' `
  -JudgeModel 'gpt-5.6-terra' `
  -Repeats 2
```

脚本不会读取仓库外的用户材料。运行者自行负责接口权限、费用和模型可用性。

## 限制

- 生成模型和评审模型固定，未做跨模型复现；
- 每个条件的重复次数少；
- 题面针对目标错误设计，不代表自然问题中的发生率；
- 评审仍由模型完成，不是独立人工评审；
- 没有测试联网检索、超长附件和多轮对话交互。

这些数据支持一次窄准入决定，不支持“CPAF 已被普遍验证”的结论。
