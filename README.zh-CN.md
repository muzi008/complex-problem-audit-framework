# 复杂问题审计框架

[English](README.md) | **简体中文**

> 一套具有明确价值立场、能够适配具体情境的复杂问题审计框架。它从范围、证据、权重、反方、不确定性、利益关系、现实约束和人的主体性等方面检查复杂判断。

**版本：** `v0.1.0-beta`  
**状态：** 公开测试版  
**形式：** 供人类、AI 或人机协作使用的模型无关协议

## 为什么建立这个项目

复杂回答经常不是输在信息不足，而是：

- 重要的信息未必可信；
- 可信的信息未必决定结论；
- 事实、推断、预测和价值选择混在一起；
- 某一方的目标被包装成中立事实；
- 理论方案无法在真实资源条件下执行；
- 回答列了许多角度，却不说明什么会推翻结论。

本框架把这些环节拆开，使结论能够被检查、质疑、更新和复用。

## 适用范围与价值立场

框架形成于中文语境、作者个人长期实践，以及对中国普通人现实约束的持续观察。它不是价值中立的计算器，也不声称代表所有国家、民族、宗教、政治制度或道德传统。

使用者可以根据当地法律、文化、宗教和个人目标调整价值权重，但不应改变核心定义、稳定编号和审计程序后，仍将结果称为同一版本。

不同 AI 可以使用不同措辞，也可能得出不同结论。统一标准指它们遵守相同概念、必填字段、证据标记和质检条件，不意味着每份回答必须完全相同。
