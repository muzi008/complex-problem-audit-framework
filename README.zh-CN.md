# 复杂问题审计框架（CPAF）

[English](README.md) | **简体中文**

> 一套用于回答和审计复杂问题的自适应规则。先让短 CORE 形成可用答案，只有确实缺少证据、变量、竞争解释、鉴别测试或行动边界时，才增加分析。

- **公开版本：** v1.1.0
- **规范版本：** 复杂问题回答框架 v3.1.1 Final
- **发布日期：** 2026-08-24
- **状态：** 正式公开版，采用 CC BY 4.0；效果证据仍有限

## 它解决什么问题

复杂回答常见两种失败。

第一种是漏。事实、推断和价值混在一起，忽略最强反方，建议没有考虑风险、资源和执行阻力。

第二种是堆。为了表现严谨，把检查表、插件名、置信百分比和推理回执全部写给用户。信息更多，判断反而更难用。

CPAF v1.1.0 的默认假设很简单：

> CORE 已经足够。任何额外分析都要说明，不做它会损失什么。

如果继续分析不会改变结论、证据需求或行动排序，就停止。

## 一个文件，一套版本

项目只把 [docs/framework.zh-CN.md](docs/framework.zh-CN.md) 当作权威规范。

CORE-3.1.1、ADAPTIVE-3.1.1、Router 和 Plugins 是这份规范内部的运行层，不是四套并行版本。prompts/ 中的短文件只是从完整规范提取的运行摘录，可以重新生成，不得反过来改写规范含义。

普通问答不应把 2800 多行完整规范全部塞进工作上下文。完整文件用于阅读、审计、维护和评测；实际回答默认使用短 CORE，发现明确缺口后再进入 Adaptive。

## 最短使用方法

把 [中文运行提示词](prompts/cpaf.zh-CN.md) 作为系统规则或项目指令，然后直接提问。

它会要求模型：

- 先确认真正问题与用户已经知道什么；
- 区分事实、推断、假设、价值和行动；
- 在适用时比较主解释与最强竞争解释；
- 在高结论偏好、重大沉没成本或高不可逆问题中，条件检查证据门槛是否对称；
- 让外部证据真正更新判断；
- 让建议适配资源、风险、可逆性和执行阻力；
- 在边际价值归零时停止。

内部的 K/Q/E/M/F、插件列表、Router 日志、结论强度标签和未校准置信百分比默认不展示。

## v1.1.0 相比 v1.0.1

- 新增条件性观察者偏差审计，只在强结论偏好、重大沉没成本、高自我相关或高不可逆问题中触发；
- 偏差只能作为待检验假设，不能写成用户隐藏动机的事实；
- 规则准入区分语义覆盖、触发覆盖、行为有效和净收益为正；
- Candidate 与 Diff 必须记录基线 SHA-256，同名文件不能替代哈希校验；
- 命题跨层和结果机制保留为 Eval 回归题，不增加常驻运行提示。

## v1.0.0 相比公开预览版

旧版 v0.1.0-beta 是 2026-07-17 发布的公开原型，主要用于说明审计维度。它已保留在 Git 标签和历史提交中。

v1.0.0 改成分层运行：

- 短 CORE 默认作答；
- Adaptive 只修复已指明的缺口；
- 插件数量允许为 0，每张插件卡都要证明可观察增量；
- 工具和自由探索按证据义务触发；
- 审计过程默认内隐；
- 加入删卡、停止和失败关闭规则；
- 把评测与版本治理写进同一份规范。

这属于公开接口的大版本升级，不保证旧提示词逐字兼容。迁移说明见 [MIGRATION.md](MIGRATION.md)。

## 已有测试

2026-08-13 完成了 10 道题、5 种条件、共 50 份匿名答案的同批次盲测。

| 条件 | 平均前台字符 | 相对 v2 FULL |
|---|---:|---:|
| 裸答 | 2,076 | 71% |
| v2.7.2.1 FULL | 2,906 | 100% |
| v3 CORE | 1,852 | 64% |
| v3 CORE + 人工方法卡 | 1,976 | 68% |
| v3 Adaptive Router | 1,905 | 66% |

50 份生成全部完成，正式答案失败 0，上下文隔离失败 0。盲评没有观察到与篇幅下降相对应的系统性质量损失，过重答案主要集中于 v2 FULL。

这批数据不能证明 CPAF 明显优于裸模型，也没有单独隔离 Tool Contract 或 Free Search 的效果。每题每条件只生成一次；模型由 UI 声明为 gpt-5.6-sol / high，程序无法核验，运行时还收到模型目录变化通知。完整限制与 Router 数据见 [测试报告](reports/v1.0-blind-evaluation.zh-CN.md)。

2026-08-24 又对观察者偏差、命题跨层和结果机制三条候选补丁做了定向筛查。首轮 9 道题生成 18 份回答、9 组盲评；观察者补丁随后追加 12 份回答、6 组盲评。

| 候选 | 补丁胜 | 旧版胜 | 平 | 处理 |
|---|---:|---:|---:|---|
| 观察者偏差 | 3 | 0 | 3 | 条件进入 CORE |
| 命题跨层 | 0 | 0 | 3 | 只保留为 Eval 回归题 |
| 结果机制 | 0 | 0 | 3 | 只保留为 Eval 回归题 |

三组控制题全部平局，没有观察到多余心理分析。该结果只支持当前题组、模型和提示条件，不等于跨模型独立验证。原始题面、逐题回答和匿名评审见 [v1.1 测试数据](evals/v1.1/README.zh-CN.md)。

正式发布前又用 Git 标签 `v1.0.1` 与待发布 `v1.1.0` 的真实运行提示重跑 30 份回答、15 组盲评。观察者目标题为新版胜 3、旧版胜 1、平 2，控制题 3 平，硬失败 0。旧版胜出的 O2 比较被完整保留；同类优势没有在另外两次 O2 重复中出现。详情见 [v1.1 报告](reports/v1.1-observer-patch-evaluation.zh-CN.md)。

| 名称 | 作用 |

| CPAF v0.1.0-beta | 旧公开预览版，保留用于历史比较 |

公开版本号和规范版本号解决不同问题。前者描述 GitHub 项目发布，后者描述框架内部演化。二者不会互相覆盖。

## 限制

- 框架改善的是回答纪律和可审计性，不能制造缺失证据，也不能保证结论正确。
- 当前证据来自数轮小规模内部盲测，观察者补丁有重复测试，但仍不是大样本独立验证。
- 医疗、法律、金融和安全等高风险问题仍需当地合格专业人士。
- 中文完整规范是语义来源；英文文件目前是参考概览，不是逐条受控翻译。
