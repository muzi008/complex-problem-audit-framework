# CPAF v1.1.0 条件性观察者偏差补丁测试报告

> 日期：2026-08-24
> 规范版本：复杂问题回答框架 v3.1.1 Final
> 生成模型：`gpt-5.6-sol`，`reasoning_effort=high`
> 评审模型：`gpt-5.6-terra`
> 证据地位：内部定向筛查，不是独立验证

## 1. 为什么测试

一次框架审计提出三条候选：条件性观察者偏差审计、命题跨层检查、结果机制检查。三条都能在理论上找到理由，但“规范里有相近文字”不能回答三个运行问题：

1. 目标情境出现时，它是否真的触发；
2. 触发后是否减少目标错误；
3. 收益是否大于输入、篇幅和误触发成本。

因此，候选不能凭文字合理性直接进入 CORE。

## 2. 设计

每条候选使用两道目标题和一道控制题，分别生成旧版 CORE 与 CORE + 单补丁答案。题面不出现评分动作，评分标准在生成前写定。答案按 A/B 匿名排列，位置交替交换。

首轮规模：

> 3 条候选 × 3 道题 × 2 个条件 = 9 道题、18 份答案、9 组成对盲评。

目标题检查候选是否修复指定错误，控制题检查多余心理分析、强行科学审计和无效怀疑。评审不得按篇幅、术语数量或文风评分。

## 3. 首轮结果

| 候选 | 补丁胜 | 旧版胜 | 平 | 硬失败 |
|---|---:|---:|---:|---:|
| 观察者偏差 | 1 | 0 | 2 | 0 |
| 命题跨层 | 0 | 0 | 3 | 0 |
| 结果机制 | 0 | 0 | 3 | 0 |

观察者补丁在三年投入、公开承诺、用户下降和现金期限并存的题中，更清楚地把“市场暂时不好”与结构性收缩作为竞争解释，并给出对称证据门槛和可逆行动。控制题没有出现对提问者心理的多余分析。

命题跨层与结果机制补丁没有输，但也没有修复旧版的可观察失败。旧版已经切断了比喻、体验、因果和高代价行动之间的不当跳跃，也已经识别入口隐藏、任务选择、分母变化和责任转移。

## 4. 成本

| 候选 | 平均输入 Token 增量 | 旧版平均输出字符 | 补丁版平均输出字符 |
|---|---:|---:|---:|
| 命题跨层 | +95 | 707.7 | 649.3 |
| 观察者偏差 | +186 | 805.0 | 842.0 |
| 结果机制 | +95 | 716.7 | 631.7 |

输出没有普遍变长，但命题跨层和结果机制仍支付了常驻输入成本，同时没有盲评收益。它们不进入压缩 CORE。

## 5. 观察者复测

观察者候选对 O1、O2、O0 各追加两次旧版/补丁版生成，共 12 份答案、6 组成对盲评。

| 题型 | 补丁胜 | 旧版胜 | 平 |
|---|---:|---:|---:|
| 目标题 | 2 | 0 | 2 |
| 控制题 | 0 | 0 | 2 |

其中一次评审把旧版遗漏三年投入形成的沉没成本判为硬失败。补丁版没有硬失败。

两轮合并后：

- 观察者目标题：补丁胜 3、旧版胜 0、平 3；
- 观察者控制题：平 3；
- 没有观察到控制题污染。

只有观察者候选通过单项准入。组合条件因此退化为 CORE + 观察者，无须把两条失败候选重新塞入运行提示；追加重复已经完成该条件的复测。

## 6. 准入决定

| 候选 | 语义覆盖 | 触发覆盖 | 行为有效 | 净收益为正 | 去向 |
|---|---|---|---|---|---|
| 观察者偏差 | 通过 | 通过 | 通过 | 当前题组通过 | CORE 条件能力 |
| 命题跨层 | 通过 | 未发现新增缺口 | 未发现独立增益 | 不通过 | Eval 回归题 |
| 结果机制 | 通过 | 未发现新增缺口 | 未发现独立增益 | 不通过 | Eval 回归题 |

正式运行规则只增加：高自我相关、强结论偏好、重大沉没成本或高不可逆问题中，检查反转结论后证据门槛是否对称、搜索是否单向，以及什么外部结果会让当前模型下降。偏差只作为待检验假设，不写成用户动机事实。

## 7. 最终运行提示发布门

候选实验并不等于正式文件验收。发布前再次读取 Git 标签 `v1.0.1` 中的真实中文运行提示，并与工作区待发布的 `v1.1.0 / CORE-3.1.1` 提示直接比较。

最终发布门共生成 30 份新回答、15 组成对盲评：9 道题先各运行一次，观察者 O1、O2、O0 再各追加两次。

| 题组 | 题型 | 新版胜 | 旧版胜 | 平 | 硬失败 |
|---|---|---:|---:|---:|---:|
| 命题跨层 | 目标题 | 1 | 0 | 1 | 0 |
| 命题跨层 | 控制题 | 0 | 0 | 1 | 0 |
| 观察者偏差 | 目标题 | 3 | 1 | 2 | 0 |
| 观察者偏差 | 控制题 | 0 | 0 | 3 | 0 |
| 结果机制 | 目标题 | 0 | 0 | 2 | 0 |
| 结果机制 | 控制题 | 1 | 0 | 0 | 0 |

观察者 O2 的三次重复分别为新版胜、旧版胜、平各一次。旧版胜出的比较中，两份答案都满足验收标准；评审认为旧版更早、更明确地区分沉没成本、公开承诺和市场假设。新版没有硬失败，旧版优势也没有在 O2 的另外两次重复中复现。

测试前曾使用“出现一次旧版胜出即否决”的过严门槛。最终提示测试说明，这会把单次生成和成对评审波动直接当成结构性退化。门槛因此修正为：总体重复结果、同类退化是否复现、控制题污染和硬失败共同决定准入。这个修正发生在看到混合结果之后，属于事后协议修正，不能冒充预注册结论；所以本报告同时公开旧版胜出的原始比较和修正理由。

按修正后的发布门：观察者目标题新版 3 胜、旧版 1 胜、2 平，控制题 3 平，没有硬失败或重复退化，CPAF v1.1.0 通过发布门。

## 8. 限制

- 每个条件的重复次数仍少；
- 生成与评审来自两个固定模型；
- 题面是定向题，不代表自然问题中的发生率；
- 模型评审可能与人工评审不同；
- 未测试检索、多轮对话、长附件和不同系统提示之间的交互；
- 模型或运行提示变化后，应重跑本题组。

完整题面、逐题答案、评审理由、脚本和汇总表见 [`evals/v1.1/`](../evals/v1.1/README.zh-CN.md)。
