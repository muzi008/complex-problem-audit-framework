# CPAF v1.0.0 盲测评估报告

- **实验批次：** 20260813_161833_screening
- **运行日期：** 2026-08-13
- **公开日期：** 2026-08-14
- **对象：** v3.0 升级方向及 v3.0.1 修订依据
- **样本：** 10 道题 × 5 种条件，共 50 份匿名答案

## 结论

这轮测试支持用 v3 CORE 替代 v2.7.2.1 FULL 作为默认运行方式。

它没有证明新框架在单次答案正确性上压过裸模型，也没有证明 Adaptive、Tools 或 Free Search 各自带来独立收益。它支持的判断更窄：

> v3 CORE、人工选卡和 Adaptive 以 v2 FULL 约 64% 到 68% 的前台字符量，保持了同一档的判断质量；盲评没有发现与缩短幅度相对应的系统性质量损失。

v2 FULL 的主要问题不是答案错误，而是把内部检查表、重复分层、执行回执和未校准置信数字带到前台。

测试后形成的 v3.0.1 Final 没有增加分析维度。它修正了 Router 权限、插件数量下限、删卡、停止、证据义务和前台显示规则。

## 条件

| 代号 | 条件 |

| B2 | v3 CORE |

## 盲评观察

被反复判为过重的答案集中于 B1。在 H02、H04、S03、S04、S05、S06 中，B1 都是该题最长或偏长的一档。

B2 平均最短。对四道复杂题，它仍完成了对象拆分、证据边界、竞争解释和结论限幅，未出现系统性漏项。

B3 在部分题上增加了结构清晰度，也有题目只增加长度。这说明方法卡需要按具体瓶颈调用，不能只因题目复杂就加载。

B4 没有普遍拖长答案，但 Router 还不能稳定找出最小插件集。

## Router 诊断

以人工预注册插件集合为参照：

| 指标 | 结果 |
|---|---:|
| 人工必选插件总数 | 21 |
| Router 命中 | 17 |
| 召回率 | 约 81% |
| Router 总选择数 | 28 |
| 属于人工必选 | 17 |
| 精确率 | 约 61% |
| 插件集合完全一致 | 3 / 10 |

集合一致率不是最终质量指标。人工选卡也可能错。这里的数据用于定位 Router 倾向：

- 某些复杂题一次选到 5 个插件；
- 一道人工判断 CORE 足够的题仍加载 P09；
- 个别题漏掉系统动力学、博弈或权力利益层，同时加入关联较弱的卡。

更合适的 Router 评价是“结果遗憾”：它相对 CORE 修复了什么真实漏项，为此增加了多少篇幅、插件和工具成本。

## 测试后进入 v3.0.1 Final 的修正

1. 插件数量取消下限，CORE 足够时为 0。
2. 每张候选插件必须说明预计改变的结论、证据需求或行动排序。
3. 初选后执行删卡反事实，只承认五类产物：新证据、新变量、新竞争模型、新鉴别测试、新行动边界。
4. 结论强度在证据处理后产生，默认不显示标签。
5. 删除前台 K/Q/E/M/F、插件列表、Router 记录和未校准置信百分比。
6. 加入停止规则。
7. 一张方法卡默认只交付一个最有区分力的产物。
8. Tools 由证据义务触发，不与 D3/D4 机械绑定。
9. Free Search 保持条件触发，没有具体异质候选时立即关闭。

这些修正已经写入 [v3.0.1 Final 完整规范](../docs/framework.zh-CN.md)。

## 不能从本轮推出什么

- 不能说 CPAF 的答案质量明显高于裸答。B0 在这 10 题上表现很强。
- 不能说 Tool Contract 已产生独立收益。系统本身会在时效、法律和事实核查题上调用工具。
- 不能说 Free Search 已产生独立收益。本轮没有单独条件。
- 不能测同一条件的重复稳定性。每题每条件只有一次生成。
- 不能把小差异全归因于框架。模型身份和推理档位未获得程序核验。
- 不能用本轮替代历史自然对照。它是同批次条件筛查，不是旧聊天答案配对。

## 配置边界

- UI 声明模型：gpt-5.6-sol
- UI 声明推理档位：high
- 主动模型覆盖：否
- 主动推理档位覆盖：否
- 程序核验：未实现
- 运行时模型目录变化通知：收到

因此，这轮数据适合做同批次的方向判断，不适合声称很小的差异必然来自框架。

## 下一轮预注册

v3.0.1 Final 已登记一轮 18 份校准测试：

- 3 道自然原话问题：事实混杂、因果与价值混合、高风险决策；
- 只比较裸答、CORE、Adaptive；
- 每种条件独立重复 2 次；
- 统一最大输出预算；
- 先做匿名成对选择，再揭盲；
- 另设停止控制题，不把框架要求写进题面。

建议通过条件包括：Adaptive 不增加决定性事实错误或漏掉高风险边界，中位长度不超过 CORE 的 110%，至少 90% 的插件调用产生可观察新增产物，无效插件率不高于 10%，并在至少一个预登记题型上重复修复 CORE 的同类漏项。

这轮后续测试尚未完成。CPAF v1.0.0 因此是“公开接口稳定”，不是“效果已经被大样本验证”。

## 公开数据边界

本报告公开实验结构、汇总数字、Router 诊断和限制。仓库不上传原题附件、50 份答案正文、私有条件映射、内部运行路径或可能含个人上下文的材料。这样可以复核结论强度，同时避免把私人测试包误当成公共数据集。
